# Walmart Sales Analytics

Power BI portfolio project focused on exploring retail sales performance through interactive reporting.

## Overview
The dashboard brings together sales KPIs and trends, making it easier to compare performance and communicate findings.

## Key areas
- Sales performance and KPI reporting
- Trends and comparative analysis
- Interactive dashboard visualizations

## Technology
Microsoft Power BI
